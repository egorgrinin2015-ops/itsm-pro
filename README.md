# 🚀 ITSM Pro v1.0

Система управления IT-заявками с современным дизайном.

## ✨ Возможности

- 🎫 Управление заявками
- 👥 Система ролей (Пользователь/Инженер/Менеджер)
- 📊 Аналитический дашборд
- 🌌 Космический дизайн
- ⏰ SLA мониторинг

## 🛠️ Технологии

- Backend: Node.js + PostgreSQL
- Frontend: React + Material-UI

## 🚀 Установка

### 1. Клонирование
```bash
git clone https://github.com/ваш-username/itsm-pro.git
cd itsm-pro
```

### 2. Backend
```bash
cd backend
npm install
cp .env.example .env
# Настройте .env файл
npm run dev
```

### 3. Frontend
```bash
cd frontend
npm install
npm start
```
